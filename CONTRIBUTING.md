# Contributing

Start with a reproducible problem or a clearly scoped improvement. Read the README's requirements and verification limits, then use synthetic fixtures and the documented test command. Keep changes focused; update instructions when behavior changes. Explain what changed, how it was tested, and what still needs live/device verification.

Never include private settings, tokens, database exports, proprietary assets or device serials. Review and understand AI-assisted changes, disclose material assistance in the pull request, and preserve source attribution.
